# 한비로 SMTP 연결 및 시험 (2026-10-02)

SMTP 서버는 derkwoo.hanbiro.net, 포트는 465, SSL 직접 연결입니다. 사용자가 전달한 456은 API 담당 터미널(term_563350d8-0bde-40f8-a08f-b337897aec6f)의 수신 확인된 465 설정을 참고하여 정정했습니다. 456 연결 시험은 시간 초과였습니다. 인증 계정과 발신 주소는 dw_ai@derkwoo.com이며 발신 표시명은 덕우전자 AX입니다. 비밀번호는 이 문서와 소스에 적지 않습니다.

## 설정

- 실제 접속 정보는 config/local.yml과 config/engine.env에 저장했습니다. 두 파일 모두 권한 600이며 .gitignore 대상입니다.
- local 프로파일의 메일 모드는 기존 LOG를 유지합니다. prod 프로파일은 기존 SMTP를 유지합니다.
- prod 설정은 PROD_MAIL_PORT, PROD_MAIL_SSL_ENABLE, PROD_MAIL_STARTTLS_ENABLE, PROD_MAIL_FROM으로 포트·SSL·STARTTLS·발신 주소를 조정합니다. 설정을 주지 않은 배포 환경의 기존 587/STARTTLS 기본값은 유지합니다. 이 저장소의 비공개 engine.env에는 465/SSL/STARTTLS 비활성화를 지정했습니다.
- 인증서 호스트 이름 검증을 활성화하며 연결·읽기·쓰기 제한 시간은 각 10초입니다. 인증서 검증을 우회하지 않습니다.
- MailChannel은 UTF-8 MIME 메일로 한글 발신명·제목·본문을 전송합니다.

`./test-mail.sh`는 실제 SMTP 채널을 사용하여 jaehoon.lee@wonderslab.kr에 시험 메일 한 통을 보냅니다. DB·조건·대기열을 사용하지 않습니다. 일반 `./gradlew test`에서는 실제 SMTP 시험을 건너뜁니다. 실제 발송을 다시 원할 때만 실행하십시오.
